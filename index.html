5석 실시간 공유 (Apps Script)

5석 상담원이 새로 저장한 접수·콜백 상태·메모를 함께 봅니다. 공유 주소가 기본으로 들어 있어 이 화면을 열면 바로 연결되고, 저장·수정·삭제가 공유 시트에 반영되며 20초마다 새로고침합니다.

기본 주소가 미리 들어 있습니다. 칸을 비우고 저장하면 이 브라우저에만 저장하고, 다른 주소를 넣으면 그 주소로 연결합니다.

설치 방법
  1. YOONSFLOW 상담접수 공유DB 스프레드시트 → 확장 프로그램 → Apps Script
  2. apps-script/Code.gs 내용을 붙여넣고 저장
  3. 배포 → 새 배포 → 웹 앱 · 실행: 나 · 액세스: 모든 사용자
  4. 나온 /exec 주소를 위에 붙여넣고 저장 → 연결 테스트

저장 방식

시트를 링크가 있는 모든 사용자 · 뷰어로 공유하면 브라우저에서 바로 읽습니다. 날짜·고객명·연락처 열은 자동으로 인식합니다.

주소의 /api/calls, /api/leads를 사용합니다. 다른 도메인에서 호출하려면 해당 서버가 CORS를 허용해야 합니다.
